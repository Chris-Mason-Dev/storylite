# StoryLite Demo

This project showcases StoryLite's component story workflow with portable HTML examples and the same
manager experience used by the React, Svelte, Vue, and Solid adapters.

## Coverage

- Buttons, cards, badges, fields, and layout stories
- Isolated previews with controls and static output
- Light and dark preview themes
- Manager and preview convention files
