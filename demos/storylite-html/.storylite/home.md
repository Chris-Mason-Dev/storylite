# HTML Demo

This project showcases trusted `?raw` HTML templates and progressive custom elements styled by a
plain CSS framework file.

## Coverage

- Buttons, cards, badges, fields, and layout stories
- Light-DOM web component stories with setup-time registration
- Light and dark preview themes
- Background presets and CSS custom property args
- Manager and preview convention files
